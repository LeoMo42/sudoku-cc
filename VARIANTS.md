# Sudoku Variant Types

## Реализованные типы (13)

### Classic
Стандартное судоку 9×9. Каждая строка, столбец и блок 3×3 содержат цифры 1–9 ровно по одному разу.

- **Генерация:** backtracking с рандомизированным заполнением диагональных блоков
- **Валидация:** строка + столбец + блок 3×3
- **Визуал:** —

---

### Diagonal (X-Sudoku)
Классические правила + обе главные диагонали тоже содержат 1–9.

- **Генерация:** перестановка цифр в жёстко заданном базовом шаблоне (`BASE_X_SUDOKU`)
- **Валидация:** + проверка двух диагоналей
- **Визуал:** фиолетовый фон на ячейках обеих диагоналей

---

### Windoku (Window Sudoku)
Классические правила + 4 дополнительных окна 3×3 (позиции: r1c1, r1c5, r5c1, r5c5) тоже содержат 1–9.

- **Генерация:** генерация классического судоку с повтором до 100 раз, пока все 4 окна не станут валидными; при неудаче — fallback на классику
- **Валидация:** + проверка 4 окон
- **Визуал:** зелёный фон на ячейках окон
- **Известная проблема:** низкая вероятность случайной генерации → почти всегда fallback

---

### Anti-Knight
Классические правила + одинаковые цифры не могут находиться на расстоянии хода конём (L-образно: 2+1).

- **Генерация:** backtracking с дополнительной проверкой по 8 ходам конём; до 50 попыток, fallback на классику
- **Валидация:** + проверка 8 ходов конём (`KNIGHT_MOVES`)
- **Визуал:** при выборе ячейки — все клетки в ходе конём подсвечиваются янтарным (`cell-knight-target`)
- **Известная проблема:** генератор часто уходит в fallback

---

### Anti-King
Классические правила + одинаковые цифры не могут находиться в соседних ячейках по горизонтали, вертикали или диагонали (ход короля).

- **Генерация:** перестановка цифр в базовом шаблоне (`BASE_ANTI_KING_SUDOKU`)
- **Валидация:** + проверка 8 соседей (`KING_MOVES`)
- **Визуал:** при выборе ячейки — 4 диагональных соседа подсвечиваются бирюзовым (`cell-king-diagonal`)

---

### Non-Consecutive
Классические правила + соседние ячейки (по горизонтали и вертикали) не могут содержать последовательные цифры (разница ≠ 1).

- **Генерация:** перестановка цифр в базовом шаблоне (`BASE_NON_CONSECUTIVE_SUDOKU`), сгенерированном Python-скриптом (`scripts/generate-non-consecutive.py`)
- **Валидация:** + проверка 4 ортогональных соседей на разницу = 1
- **Визуал:** статичные оранжевые точки на всех внутренних границах между ячейками

---

### Odd-Even
Классические правила + часть ячеек помечена маркерами: круг = нечётная цифра, квадрат = чётная.

- **Генерация:** классическая генерация + случайная расстановка маркеров (~35% ячеек) на основе готового решения
- **Валидация:** + проверка соответствия цифры маркеру в ячейке
- **Визуал:** синий кружок (нечётные) / оранжевый квадрат (чётные) в левом верхнем углу ячейки

---

### Kropki
Классические правила + на границах между соседними ячейками расставлены точки: **белая** = разница ровно 1, **чёрная** = одна цифра вдвое больше другой. Отсутствие точки означает, что ни одно из этих отношений не выполняется.

- **Генерация:** классическое решение → расставить точки по правилам (ключ: `"row,col,r"` / `"row,col,b"`)
- **Валидация:** + проверка пар ячеек с точками; для ячеек без точки — ни разница=1, ни отношение 2:1
- **Визуал:** маленькие кружки (2.5×2.5px) на границах ячеек; белые — `bg-white border-gray-800`, чёрные — `bg-gray-900`

---

### Killer Sudoku
Классические правила + ячейки объединены в «клетки» (cages) с заданной суммой; внутри клетки цифры не повторяются. Доска начинается полностью пустой.

- **Генерация:** классическое решение → случайная кластеризация в клетки по 2–5 смежных ячеек → вычисление сумм
- **Валидация:** + внутри клетки нет повторений; при заполнении всей клетки — сумма = целевой
- **Визуал:** пунктирные фиолетовые границы клеток (2px, `#7c3aed`); сумма клетки в левом верхнем углу (9px, violet-700)

---

### Little Killer
Классические правила + снаружи сетки у диагональных направлений стоят числа — суммы всех ячеек вдоль этой диагонали. Цифры на диагонали **могут повторяться**.

- **Генерация:** классическое решение → случайно выбрать ~10 диагоналей длиной ≥ 2 → вычислить суммы
- **Валидация:** если вся диагональ заполнена — сумма должна совпадать; если частичная сумма уже превышает целевую — ошибка
- **Данные:** `littleKillerClues: [{ labelRow, labelCol, dr, dc, cells, sum }]`; `(labelRow, labelCol)` — позиция метки за пределами сетки (-1 или 9)
- **Визуал:** стрелка (↘↙↗↖) + число суммы снаружи сетки (indigo-700); доска получает дополнительный отступ 35px вокруг

---

### Thermo (Thermometer)
Классические правила + вдоль каждого «термометра» (цепочки ортогонально смежных ячеек) цифры строго возрастают от луковицы (bulb) к кончику (tip).

- **Генерация:** классическое решение → случайные цепочки длиной 3–6, где значения монотонно возрастают; до 6 термометров без пересечений
- **Валидация:** для ячейки на позиции `i`: все заполненные ячейки до неё должны быть < текущего значения, все после — >
- **Данные:** `thermos: Array<Array<{row, col}>>` — plain JSON, без Map
- **Визуал:** серая «труба» (14px) внутри ячеек + большой круг-луковица (32px) на первой ячейке; рендерится под числом через `z-index: 1`; стабильные ссылки на объекты через `useMemo` для корректной работы `memo(Cell)`

---

### Sandwich Sudoku
В каждой строке и столбце — сумма цифр, находящихся **между** цифрами 1 и 9.

- **Генерация:** классическое решение → для каждой строки/столбца найти позиции 1 и 9, просуммировать цифры между ними
- **Валидация:** если оба 1 и 9 расставлены, частичная сумма не должна превышать целевую; при полном заполнении — сумма должна совпадать
- **Данные:** `sandwichClues: { rows: number[], cols: number[] }` — 9 сумм по строкам + 9 по столбцам (plain JSON)
- **Визуал:** числа снаружи сетки (слева от строк `#1e40af`, над столбцами `#1e40af`); доска получает дополнительный отступ 40px слева и сверху

---

### Greater Than (Inequality)
Классические правила + между **всеми** соседними ячейками (по горизонтали и вертикали) стоят знаки `<` / `>`, которым должны удовлетворять цифры.

- **Генерация:** классическое решение → вычислить знак для всех 144 внутренних рёбер (`"row,col,r"` и `"row,col,b"`)
- **Валидация:** при размещении цифры проверить все заполненные соседи; знак описывает отношение левой/верхней ячейки к правой/нижней
- **Данные:** `greaterThanSigns: Map<string, '>'|'<'>` — 144 записи, ключ как у Kropki
- **Визуал:** знаки `<`/`>` (горизонтально) и `∧`/`∨` (вертикально) на границах ячеек, 9px indigo-700, белый фон 14×14px

## Цветовая схема

| Состояние | Цвет |
|-----------|------|
| Выбранная ячейка | синяя рамка (`ring-blue-500`) |
| Та же строка/столбец/блок | `blue-50` |
| Диагональ (X-Sudoku) | `purple-100/200` |
| Windoku-окно | `green-100/200` |
| Ход конём (Anti-Knight) | `amber-100/200` |
| Диагональный сосед (Anti-King) | `teal-100/200` |
| Точки Non-Consecutive | `orange-400` |
| Точки Kropki: белая | `white` с рамкой `gray-800` |
| Точки Kropki: чёрная | `gray-900` |
| Killer: граница клетки | `#7c3aed` (violet), dashed |
| Killer: сумма клетки | `violet-700`, 9px |
| Little Killer: стрелка+сумма | `indigo-700` / `gray-800`, 10–11px |
| Greater Than: знаки неравенства | `indigo-700`, 9px, белый фон 14×14px |
| Thermo: труба и луковица | `gray-300`, tube 14px, bulb 32px |
| Sandwich: числа снаружи | `#1e40af` (blue-800), bold, 12px |
| Ошибка | `red-100` |
